# SkillMatch+

A Flutter mobile app that helps job seekers match their skills against real
job postings, track applications, and close skill gaps for their target
career path.

## Features

- Email OTP-based sign up, sign in, and password reset
- Job listings with skill-match scoring against your profile
- Application tracking with status timeline
- Career pathway and skill-gap analysis backed by a curated IT roles/skills
  dataset
- Profile management with resume upload

## Getting started

```bash
flutter pub get
flutter run
```

The app talks to the Node.js backend in `backend/` — see
`backend/README.txt` for setup instructions.
